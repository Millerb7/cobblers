# kits/structures/foliage

Tree, debris and understory objects for WorldPainter custom object layers. Every `.nbt` is a Minecraft
structure template (1.21.1) with a sidecar `.json` holding its group, source and origin (the template coordinate
of its base column). `library.json` indexes them: size, height, crown radius, trunk footprint, eye-level width and
sha256.

- `<group>_NN.nbt` from `harvest`: captures of vanilla configured features (`/place feature`), one real tree each.
- Everything else from `generate`: seeded code in `tools/foliage_objects.py` and `tools/landmark_trees.py`,
  regenerated byte for byte. The swamp groups (`mangrove`, `tall_mangrove`, `mangrove_scrub`, `swamp_giant`,
  `vine_snag`, `root_tangle`) serve the `data/foliage.json` overlays (`docs/world-building/FOLIAGE_MARSH_JUNGLE.md`).

Rebuild the index with `python tools/foliage_objects.py index`. Placement and forest identity:
`docs/world-building/FOLIAGE.md`.
