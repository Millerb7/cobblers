# tests/

Fast, network-free checks on the repository's data and tooling. Run from the
repo root:

```
python -m pytest tests -q
```

| Test file | What it guards |
|-----------|----------------|
| `test_validate_runs.py` | `tools/validate.py` exits 0 on the repo and still lists its extension-point checks. |
| `test_manifest_consistency.py` | every hash in `base-pack/inventory/pack_hashes.csv` is in the base manifest; overlay `replace` / `remove` / `server_exclude` / `needs_functional_test` reference only mod ids that exist in the base (or in `add`); `server_exclude` equals the set of client-only mods; verified replacements carry a version id, URL and sha512; `plan --side server` leaks no client mod and contains Cobblemon 1.8.0. |
| `test_blackout_pack.py` | the generated `cobblers_blackout` pack: checkpoint ids cover every Center and town waystone and are never renumbered; validate, the charge, the dedupe, the Surf/Dive timers and the drowning hit, run on a small scoreboard simulator; claim categories and scan slots; claim-before-take and resolve-before-release order; macros, objectives, callbacks under `data/cobblemon/`; the Respiration override and the Dive swim modifiers. |
| `test_surface_exhaustion.py` | the pack's `surface/*` swim fatigue: every swim tires, in any water, with no map; the deep doubles, a partner halves; land, wading and riding recover; the ride flag does not carry between players; a trained player under water neither tires nor recovers, an untrained one does; `bo.surf` starts at 0; collapse reuses `water/pulse`, first hit as collapse is reached then one every `pulse_ticks` of time; the tick runs every `sample_ticks`; only the boat rows need the heightmap. |
| `test_boats.py` | boats as shallows craft (option C): `tools/blackout_pack.py` main()'s boat rows are `tools/open_water.py`'s bands at the data's distances (on a synthetic ground); rough water tips a boat or chest-boat rider out with the message, shallows and a ringed lake do not; a ridden Pokemon is not a boat; the check runs for a rider whose feet are dry; the sheltered boxes are exactly the data's, to the block; the check's cell is the band map's; on the real heightmap (slow) every cell row has a row, and the bay and the apron are sheltered while the open sea round them is not. A tipped rider swims that sample. |
| `test_system_contracts.py` | the cross-system contracts registered in `data/system_contracts.json`, each run with the systems together as generated: Dive unlimited and Surf's whole bonus at depth with swim fatigue running, the ferry's gates re-walked on the heightmap, boats (option C) not reopening a gated strait (slow), no world pack placing a spawn condition its place is not whitelisted for, a claim surviving a simulated re-export, every built ward (the gulch gate, the seam) keeping what it guards out of reach, every gate and ward opening on a flag the progression pack grants, a gulch Mega making no claim, the gulch's zone and build off Victory Road, no repeatable player action resetting an accumulating gate clock (C14; the seam's ward against milk is a strict xfail today); and the registry itself (tests exist and are registered, a consumer other than the owner, citations still quote their lines, failing contracts recorded and marked strict). |
| `test_gate_clocks.py` | the scenarios contract C14 runs: each clock a gate relies on (swim fatigue, the collapse clock, the Surf bonus, the drowning pulses, the blackout dedupe, the gulch Megas' respawn clock, the ferry cooldown, the wards) against each action a player can repeat (relog, restart, a boat each sample, a touch of land, bobbing, re-approach, milk); and harness tests that each scenario fails on a pack changed to make its reset. |
| `test_gulch_mine.py` | the southern Rift's mega site (`tools/gulch_mine.py`, on `tests/gulch_sim.py`'s world model): the knock, zone, exit and ward both ways on `gym6_cleared`; the zone boxes exactly the polygon's columns, knock and turn-back outside, arrival and exit inside; every Cutter offer 4 raw + 1 diamond, unlimited, no xp, the sixty stones of SOUTHERN_RIFT_MEGA.md 7.3 by name (and the jars' 92, skipped without them); faces restored once per period, on approach, loaded and empty, filtered so a chest survives, three crystals one showing, never the same variant twice (the 15-minute offset between faces is a strict xfail); the Megas uncatchable, tagged with the blackout's exempt tag, leashed, owed again, de-duplicated; no meteorid ore; `tools/mega_recipes.py` raising all 92 recipes to 4 raw and writing only under build/; step R9S after R9M. With the heightmap (slow): the built pack's blocks, grid and zone, the ward's reach and the Megas' anchors. |
| `test_carry_recovery_ledger.py` | `tools/carry_players.py` with the claim ledger: the ledger file is the pack's ledger namespace and is carried byte for byte; the shared `cobblers` storage never is; a world without scores is refused; the badge check is still reached. |
| `test_compile_spawns_sky.py` | which compiled spawn conditions require `canSeeSky` (land and surface do; submerged and seafloor must not), per entry and over the whole compiled output. |
| `test_water_mounts.py` | `data/water_mounts.json`: Surf and Dive lists disjoint, bare lowercase ids, each a Cobblemon 1.8.0 species (skips without the jar). |
| `test_themed_saplings_tool.py` | `tools/themed_saplings.py`: the build places each tree at its pin and never re-picks; nests bottom-up; `records --write` keeps a placed status only where the position is unchanged. |
| `test_rift_mines.py`, `test_rift_mines_ward.py`, `test_rift_mines_review.py` | the cut-back Rift dig camp mines: rasterisers alike (live and retired), the audit's plan checks on a made-up mine, the data (gym6 flag, no spawn blocks, a filtered daily restore), R9M and the staging-only refill never installed; the seam's crystal behind the grille, the ward per player and out of reach; on the built packs (slow) one crystal, sealed, no retired gate, the refill exactly the retired envelope, and the audit's mutations (a pack without its grille audits clean: strict xfail). |
| `test_no_eula.py` | no tracked (or untracked-but-not-ignored) text file accepts the Minecraft EULA, and no `eula.txt` is tracked. |

`conftest.py` provides `repo_root`, `tracked_files` (git-known plus untracked
non-ignored files, so new work is checked before it is committed) and `python`.

These tests do not touch Modrinth and do not need any jars. Regenerating the
manifest (`tools/pack_manifest.py generate`) is a separate, deliberate step.
