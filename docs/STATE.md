- **Live world:** `cobblers-10240` under the local `cobblers-server` runtime; `level.dat` reports spawn `(1461, 118, 5306)`, 484 overworld region files, and a matching 10,240-block border.
- **Runtime:** Minecraft 1.21.1, Fabric Loader 0.19.5, Cobblemon 1.8.0+1.21.1, and Java 21; the latest live log reached `Done (2.659s)`. Trainers are rctmod 0.19.0-beta on rctapi **0.16.1-beta**, pinned in `modpack/manifest/overlay.json` over Cobbleverse's 0.16.0 because 0.16.0 softlocks a battle when both sides faint at once (rctapi #132; Brock froze on staging 2026-09-24, `docs/research/notes/battle-freeze-double-ko.md`). Installed on the server; the fix is not yet reproduced in game.
- **Never switch a placed Habitat Block's style with `data merge`** (staging, 2026-09-26). Cobblemon 1.8.0's `HabitatBlockEntity` builds its spawn details once, on its first tick (`initialized` flag, not saved), and the activated style (`SpawningStyle: "cobblemon:activated"`, keys `Chance`, `Trigger`, `CancelRange`, `SpawnRange`, `MaxSpawns`, `MaxSpawnsPerActivation`) keeps its spawner in a lateinit field that only that step fills. `tools/habitat_blocks.py`'s setblock-then-merge pattern hands an already-initialised block a fresh activated style with no spawner: its tick throws, and so does every player spawning pass that reaches it. A block the owner configured by hand in the editor works (a Flamigo flock, 2026-09-26). What works by command (staging, 2026-09-26, 158 blocks, no error): set the position to another block first (re-placing a habitat block keeps its old, initialised entity), then one setblock carrying the whole NBT, including `PhaseOrder` (read with valueOf, not defaulted: leaving it out makes the setblock fail half-loaded). `tools/habitat_blocks.py` writes activated blocks that way. Neruina froze the block, then kicked the player, and wrote `neruina$errored` into that player's saved data, which silently stopped all Pokemon spawning around that player across restarts until the key was removed from the offline player file.- **Cobblemon's spawn command does nothing inside a function** (staging, 2026-09-25): `spawnpokemonat` from the console spawns, the same line in a datapack function spawns nothing, and vanilla `summon cobblemon:pokemon` is refused even with a full Pokemon compound. A Pokemon the campaign places is summoned over RCON by `tools/reapply.py` (its `cmd` action), never by a pack.
- **rctmod never refuses a rematch with a placed trainer (standing limitation).** A trainer placed with `summon_persistent` (every trainer we or a gym place) skips rctmod's "already beaten by this player" check entirely: `TrainerMob.couldBattleAgainst` returns true for a persistent trainer before it looks (rctmod 0.19.0-beta bytecode; the owner re-battled a persistent Brock straight after beating him, no restart, 2026-09-24). For the others the check (`winsAndDefeats` against `maxTrainerDefeats`) lives only in the loaded entity and is never saved, so a restart or chunk unload forgets it (the owner beat Channeler Hope twice across a restart). What rctmod does persist is the player's own defeat count and series progress, which gate loot conditions and requirements, not rematches. Our trainers are held off by `tools/route_trainers.py`'s cycle: a player tag mirrored from their own defeat field, and a short trainer `Cooldown` while only players who beat it are near. Design against rctmod as if it forgets every win.
- **Seed:** retained in the live `level.dat`, deliberately uncommitted, and identified only by SHA-256 `48202407c92bc5d07cd215b93f631b384a5f7dde58e993e7bc9f7365e03563f3`.

## What is decided

- **Base and target:** preserve the Cobbleverse experience through an overlay while targeting Cobblemon 1.8.x on Minecraft 1.21.1 Fabric.
- **Live-world isolation:** agents check process/port and acquire `C:\Users\wnd\Documents\github\.cobblers-server-agent.lock` before any server-runtime access; agents never read `cobblers-server/cobblers-10240/`, and disposable worlds are seeded only from designated offline snapshots.
- **Spawn philosophy:** use curated exclusive pools on critical-path route corridors and keep the default Cobbleverse pool open in wilderness and postgame areas.
- **Map geometry:** use 1,024-block square planning cells, terrain-following region polygons, and no hex grid.
- **Vertical scale:** use the Option B rescale above `y145`, with authored terrain capped at `y310` and the runtime ceiling raised to `y575`.
- **World source:** commit reproducible heightmaps, WorldPainter sources, templates, data, and tools; do not treat the live save as source code.
- **Licensing:** only MIT-style (permissive) sources may be committed; anything else is used locally and gitignored, and every structure template needs a `kits/PROVENANCE.json` record, enforced by `python tools/validate.py --only template_provenance`.
- **Structure placement:** place campaign structures deliberately and do not enable donor packs as uncontrolled natural world generation.
- **Recognizable towns:** use CobblemonCityTowns first, then compatible licensed donor libraries, with minimal custom connectors and a donor manifest.
- **Navigation:** use waystones only for fast travel, with gym-clear progression flags controlling gym-town activation.
- **Dialogue:** native Cobblemon dialogue rather than KantoNPCs, compiled from campaign data by `tools/compile_dialogue.py`; quest fields and the cursor live in Cobblemon player data (`q.player.data()`, persisted per player); item checks use the vanilla item predicate run as the server; every give reports success and a reward claim depends on it (EXP-022: disconnect restore, bucket and bottle hand-over, reward once all pass single-player).
- **Dialogue cursors:** store long-sequence position as first-class per-player state and persist it after each line or short segment.
- **Legendary side content:** paste a compatible structure into a fitting biome and gate it by badge count; only the authored Regis/Regigigas/Groudon/Lugia encounters and the mainline Celebi sapling receive bespoke treatment.
- **Quest namespaces:** reserve progression gates as `flags.<id>` and side-quest fields as `quest.<quest_id>.<field>`.
- **Gastly escort:** each player owns and advances an independent Gastly escort; there is no shared-party quest state.
- **Every Cobblemon item is obtainable without crafting** (the owner, 2026-09-24): crafting stays allowed, but the game must be completable, and every Cobblemon item reachable, through natural sources alone (world finds, rewards, trainers, shops, fishing, events), so a no-crafting run such as a Nuzlocke works.
