# EXP-065: Smeargle, the seventh starter: three forms, Protean, the fast pivot, and the U-turn TM

**Status: NOT RUN. BUILT, NOT OBSERVED IN GAME (2026-10-08).** Everything below is from code and the 1.8.0 jar.
Valid JSON is the most that has been shown.

**The Sketch cap is OFF** (the owner, 2026-10-08: "remove the cap for smeargle's sketch for now"). It is kept as
`superseded_sketch_cap` in `data/mythical_starters.json`, and the pack carries no `sketch.js` and no callbacks. Steps 4
and 5 below run only once the cap is switched back on.

## Objective

Show in a running server that the seventh starter works as decided (the owner, 2026-10-08; `docs/STATE.md`
"Smeargle, the seventh starter"; the pivot: `docs/research/notes/smeargle-pivot.md`):

1. the 30 and 45 steps are same-species form changes (`cobblers_starter_1` -> `_2` -> `_3`), each offered;
2. Protean is the ability in all three forms, kept across both steps;
3. Sketch copies a move for good and the copy stays when Sketch is benched;
4. (cap on only) the 11th Sketch fails with "But it failed!";
5. (cap on only) the count survives the PC, a trade and a restart;
6. the native TM Machine teaches U-turn to a starter Smeargle, and not to a wild one;
7. the pivot, played against Sabrina, Lorelei and Agatha, before trusting the measure.

## Success criteria

Each step passes or fails on its own.

- Steps 1 and 2 decide whether the line stands as built. **Step 1 depends on EXP-049 step 3** (a same-species
  evolution moving form to form), which has never run; Smeargle needs it twice. If EXP-049 step 3 fails, this line
  fails with it, and the four other same-species lines do too.
- Step 3 decides that Sketch is the movepool.
- Step 6 decides the U-turn TM. If a starter Smeargle gets `tms.cannot_learn`, the form's `tm:uturn` entry is not
  being read and U-turn comes only through Sketch (the pivot note section 1).
- Step 7 is a balance reading, not a pass/fail: it says whether the 476 pivot plays as the note predicts.

## Dependencies

- Staging server and a staging world (never `cobblers-10240`), with `cobblers_mythical_starters` rebuilt
  (`python tools/mythical_starters.py build`) and installed, then a restart.
- For step 6: 7 bug gems and a Shed Shell, a TM Machine, and the U-turn TM unlocked for the test player
  (`data/cobblemon/tms/uturn.json` is `cobblemon:unlockable`).
- Two players for the trade in step 5 (cap on only).
- EXP-049 step 3 first, or run alongside it.

What is built (all generated by `tools/mythical_starters.py` from `data/mythical_starters.json` `starter_smeargle`):

|---|---|

The U-turn entry, read in the 1.8.0 jar: a `tm:` learnset entry fills `Learnset.tmMoves` (the static `tm`
interpreter); `FormData.getMoves` returns the form's own learnset when it sets `moves`; `TechnicalMachineItem` refuses
with `tms.cannot_learn` unless `pokemon.getForm().getMoves().tmLearnableMoves()` contains the move, and
`TechnicalMachine.filterTms` filters the machine by the same list. The entry is recorded in the line's
`tm_additions` with the owner's decision. `mythical_starters.py check` and `mythical_starters_audit.py` refuse any
other non-native `tm:` entry.

The starter screen offers `smeargle level=5 aspect=cobblers_starter_1`; Oak's lab has a seventh stand at
(1501, 118, 5312), one row behind Meltan.

## Test instructions

Run on staging as an operator. Read each value from the summary screen or `/pokemonedit`.

1. **Forms.** Pick Smeargle on the starter screen. Expect level 5, form Starter, 64/47/54/47/54/64, ability
   Protean. Give it Rare Candy to 30 (with the cap raised for the test, or after the badges): the evolution is
   offered; accept it. Expect Starter-Grown, 83/61/71/61/71/83. Repeat at 45: Starter-Final, 92/68/78/68/78/92.
   Check that a wild Smeargle (`/pokespawn smeargle`) is the plain 250 species with Own Tempo, Technician or Moody.
2. **Protean.** At each form, the ability reads Protean. In a wild battle, use Flamethrower first: Smeargle turns
   Fire; use a Normal move next: it stays Fire (Gen 9, once per switch-in). Switch out and in: it can change again.
3. **Sketch copies and benches.** Against a wild Pokemon that has used a move, use Sketch. Expect the battle's
   Sketch line naming the copied move, the copy in Sketch's slot after the battle, and Sketch on the bench
   (re-slottable from the summary). With the cap off, no chat line and no count.
4. **The cap (cap on only).** Set the count to 9 (`/pokemonedit <slot> dmax_level=9`), Sketch once more (count 10,
   the chat says "From now on, Sketch will fail."), re-slot Sketch, and use it in the next battle. Expect "But it
   failed!", the moveset unchanged, and the count still 10.
5. **The count survives (cap on only).** With the count at a known value: PC, trade, restart; read the count each
   time.
6. **The TM Machine teaches U-turn.** Craft the U-turn TM at a TM Machine (7 bug gems, a Shed Shell) and use it on
   the starter Smeargle at each of its three forms (Starter, Starter-Grown, Starter-Final). Expect `tms.teach_move`
   and U-turn among its moves, with no Sketch used. Then use one on a wild-caught Smeargle: expect
   `tms.cannot_learn` (the plain species has no `tm:` entry). Note whether the machine lists the U-turn disc for the
   starter Smeargle and not for the wild one (`TechnicalMachine.filterTms`).
7. **The pivot** (the pivot note section 8). Fight Sabrina, then Lorelei and Agatha, with the 476 form, U-turn from
   step 6, and three attacks of different types.
   1. **Entry type.** On every switch-in, Smeargle shows as Normal. After its first move it shows the move's type,
      and only one change per stay. (Verify `-start typechange` in the battle log, and no second change.)
   2. **U-turn first.** Used as its first move, U-turn turns it Bug and hits for STAB. Compare the chip with one used
      after an attack.
   3. **Speed order.** Against a slower foe, the partner takes the foe's hit that turn. Against a faster foe that it
      survives (Froslass, Mismagius), the partner comes in free. Note which happened.
   4. **The entry hit.** Hard-switch into a Psychic from Sabrina and a Lorelei Ice move, and record the % lost.
      Predicted top rolls at 476 (no crits): Sabrina's Alakazam, Psychic 83%; Hatterene, Psychic 58%; Mamoswine,
      Earthquake 89%; Jynx, Focus Blast 89%; Froslass, Icy Wind 21%. Never test a switch into Bruno.
   5. **The return.** Bring it back after the partner and check that it is Normal again, and that its next attack
      picks a new type with STAB.
   6. **Sketch.** Copy U-turn instead from a level-30 Gligar or Mienfoo, or from Giovanni's Persian. It works only
      after the target has used U-turn in that battle. Check that the move is still there after the battle, and
      that it can be re-slotted from the bench.
   7. **The RCT AI.** Does the leader switch out against a type it reads as bad? `battle_sim` never switches the
      leader, and every leader declares `switchBias` 0.65.
